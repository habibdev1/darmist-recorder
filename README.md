# Darmist Screen Recorder

A simple, client-side screen recorder built with HTML, CSS (Bootstrap), and JavaScript. This tool allows users to record their screen and audio directly from their browser, with options to select different recording resolutions.

## Features

*   **Screen Recording:** Capture your screen activity.
*   **Audio Recording:** Record system audio along with the screen.
*   **Resolution Selection:** Choose from default, HD (1280x720), Full HD (1920x1080), or 4K (3840x2160) recording resolutions.
*   **Instant Download:** Download recorded videos directly to your device as MP4 files.
*   **Intuitive Interface:** Clean and easy-to-use controls.

## Technologies Used

*   **HTML5:** For structuring the web page.
*   **CSS3 (Bootstrap 5):** For responsive and modern styling.
*   **JavaScript:** For implementing recording logic using `MediaRecorder` API and user interaction.

## How to Use

1.  **Open the Application:** Open `index.html` in your web browser.
2.  **Select Resolution:** Choose your desired recording resolution from the dropdown menu.
3.  **Start Recording:** Click the "Start Recording" button. Your browser will prompt you to select which screen or application window you want to share.
4.  **Stop Recording:** Click the "Stop Recording" button to finish the recording.
5.  **Download Video:** Once stopped, a video preview will appear. Click "Download Video" to save the recorded MP4 file to your computer.

## Local Setup

To run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone git@git.darmist.com:open-source-projects/darmist-recorder.git
    cd darmist-recorder
    ```
2.  **Open in Browser:** Simply open the `index.html` file in your preferred web browser. No local server is required.
